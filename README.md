# Sacred Blueprint · WebXR

Συλλογή εικονογραφημένων εκπαιδευτικών κόσμων για browser και συμβατό εξοπλισμό VR.

**[Άνοιγμα συλλογής](https://dporpatonelis-crypto.github.io/sacred-blueprint-webxr/)** · [Πρώτος κόσμος: Από το κατ’ εικόνα στο καθ’ ομοίωση](https://dporpatonelis-crypto.github.io/sacred-blueprint-webxr/lessons/eikona-talanta-loukas/)

Ο πρώτος κόσμος περιέχει 16 αντιστοιχίσεις και 12 κινούμενες απεικονίσεις. Ο [δεύτερος κόσμος, Η Θεία Οικονομία](https://dporpatonelis-crypto.github.io/sacred-blueprint-webxr/lessons/theia-oikonomia/), περιέχει 20 αντιστοιχίσεις, 16 κινούμενες απεικονίσεις και τελικό χάρτη εννοιών. Κάθε κόσμος έχει εικονογραφημένο πανόραμα 360°, τρισδιάστατα περάσματα και επιμέρους αυλές με ποτάμια.

Η πρώτη γέφυρα είναι έτοιμη. Μπροστά στον σταθμό ο παίκτης γεμίζει με water blaster το δοχείο της σωστής απάντησης και ανοίγει την επόμενη γέφυρα. Τα δοχεία ενεργοποιούνται ήδη στην εισερχόμενη γέφυρα. Υποστηρίζονται ποντίκι/πληκτρολόγιο, χειρισμός αφής και χειριστήρια WebXR. Οι αρχικές πηγές ImageGen, τα πραγματικά GIF, τα atlas και τα prompts διατηρούνται μαζί με το έργο.

Σε VR, ο **αριστερός μοχλός** κινεί τον παίκτη μπροστά/πίσω και πλάγια, με βάση την κατεύθυνση του βλέμματος. Ο **δεξιός μοχλός** στρέφει κατά 45° γύρω από την πραγματική θέση του headset. Η βάδιση ακολουθεί τα ίδια όρια, εμπόδια και ανοιχτές γέφυρες με τον χειρισμό desktop/αφής. Τα σημεία τηλεμεταφοράς και το trigger για νερό/επιλογή παραμένουν διαθέσιμα.

## Δομή

```text
apps/                         Ανεξάρτητα έργα WebXR
  eikona-talanta-loukas/
    src/                      Κώδικας και δεδομένα μαθήματος
    public/                   Runtime εικόνες και atlas
    media/                    Αρχικά GIF, sprite sheets, πανόραμα
    prompts/                  Prompts παραγωγής και διορθώσεων
    qa/                       Έλεγχοι μαθήματος/media
  theia-oikonomia/             Δεύτερος κόσμος, με την ίδια δομή
shared/journey/               Κοινός χειρισμός, γέφυρες, νερό και προβολή καρέ
shared/node/                  Κλήσεις FFmpeg με όριο χρόνου
site/                         Κεντρική σελίδα και προεπισκοπήσεις
lessons.json                  Κατάλογος δημοσιευμένων κόσμων
scripts/                      Ενιαίο build και τοπική προεπισκόπηση
docs/adding-a-world.md         Οδηγός επόμενων κόσμων
```

Κάθε κόσμος δημοσιεύεται στο lessons/<id>/. Το build της συλλογής παράγεται στο dist/ και δημοσιεύεται αυτόματα με GitHub Actions. Στο GitHub ανεβαίνει ο πηγαίος κώδικας και τα επιλεγμένα media· οι εξαρτήσεις και τα παραγόμενα build δεν δεσμεύονται στο Git.

## Τοπική χρήση

Χρειάζονται Node.js 22.12+ και npm. Για τους ελέγχους GIF και την προετοιμασία εικόνων χρειάζονται FFmpeg/FFprobe.

```sh
npm ci
npm test
npm run build
npm run preview
```

Η προεπισκόπηση της συλλογής ανοίγει στη θύρα 5190 και χρησιμοποιεί Python 3. Με npm run dev ανοίγει η πρώτη εφαρμογή στη θύρα 5191. Η φιλοξενούμενη έκδοση λειτουργεί χωρίς εγκατάσταση Node ή Python.

## Επόμενοι κόσμοι

Προσθέτουμε ανεξάρτητο έργο στο apps/, μια προεπισκόπηση και μια εγγραφή στο lessons.json. Η κεντρική σελίδα και η δημοσίευση ενημερώνονται από τον ίδιο κατάλογο. Αναλυτικά: [Προσθήκη νέου κόσμου](docs/adding-a-world.md).

Η πρόοδος διατηρείται στον browser με ανεξάρτητο κλειδί ανά μάθημα και ξεχωριστή αποθήκευση για τον μηχανισμό νερού. Η online έκδοση ξεκινά ανεξάρτητα από το localhost. Η παρουσία λειτουργίας VR εξαρτάται από τον browser/headset· η δοκιμή σε φυσικό headset παραμένει ξεχωριστός έλεγχος.

## Ιστορικό αποθετηρίου

Το αποθετήριο προέρχεται από το EusebiusQuest-Data, το οποίο μετονομάστηκε αντί να διαγραφεί. Το προηγούμενο ιστορικό διατηρείται και το game_data.json παραμένει αυτούσιο στη ρίζα για αναφορά. Δεν αντιγράφεται στο δημοσιευμένο site.
