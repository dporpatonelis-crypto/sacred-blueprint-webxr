# Πεντηκοστή · WebXR στο Υπερώο των Ιεροσολύμων

Συναρμολόγησε την εικονογραφημένη κοινότητα, σύνδεσε έξι σύμβολα με τον ύμνο μέσω δοχείων νερού και τοποθέτησε τις έξι φράσεις του ύμνου σε δύο γύρους.

Τοπική προεπισκόπηση: `npm run dev --workspace=apps/pentecost-journey` στη θύρα 5222. Η πρόοδος αποθηκεύεται χωριστά για αυτόν τον κόσμο.

Οι αρχικές εικόνες και τα αρχεία προέλευσης βρίσκονται έξω από το δημόσιο `public/`. Το skybox προέρχεται από το Jerusalem panorama της περιόδου Χριστού/Ηρώδη στο MindPalaceVR.
