# Ο Πύργος της Βαβέλ · WebXR στη Σεναάρ

Προεπισκόπηση με παζλ 3×2 και έξι διαδοχικούς σταθμούς νερού. Η κύρια εικόνα προέρχεται από το HTML μάθημα· το νέο panorama της Σεναάρ συνοδεύει την τρισδιάστατη πεδιάδα και τον πύργο υπό κατασκευή.

Για τοπική προεπισκόπηση από τη ρίζα του repo:

```sh
npm run dev --workspace=apps/babel-tower
```

Το μάθημα διατηρείται ως `draft` στον κατάλογο μέχρι να ελεγχθεί. Η πρόοδος αποθηκεύεται με ξεχωριστό κλειδί browser για αυτόν τον κόσμο.
