# Η Θεία Οικονομία · WebXR

[Άνοιγμα μαθήματος](https://dporpatonelis-crypto.github.io/sacred-blueprint-webxr/lessons/theia-oikonomia/)

Τέσσερις αντιστοιχίσεις στον κεντρικό χάρτη και τέσσερις σε κάθε ενότητα: **20 συνολικά**. Η ασθένεια είναι ιατρική παρομοίωση, όχι τέταρτη φάση. Οι τρεις φάσεις είναι Παλαιά Διαθήκη, Καινή Διαθήκη και Εκκλησία. Τα αρχικά IDs, τα κείμενα, οι υποδείξεις, οι επεξηγήσεις και ο τελικός χάρτης εννοιών διατηρούνται από το αρχικό μάθημα.

## Διαδρομή και χειρισμός

Η πρώτη γέφυρα είναι έτοιμη. Μόλις ανέβεις στην εισερχόμενη γέφυρα εμφανίζονται τα δοχεία του σταθμού. Κράτησε την κάρτα ή στόχευσε το σωστό δοχείο με το water blaster για περίπου 1,5 δευτερόλεπτο. Κάθε σωστή απάντηση ανοίγει ολόκληρη την επόμενη γέφυρα· η τελευταία ανοίγει την επιστροφή. Σε λάθος το δοχείο αδειάζει. Μετά το δεύτερο λάθος εμφανίζεται υπόδειξη. Άφησε τη βολή πριν απαντήσεις ξανά.

WASD ή βελάκια για βάδισμα, σύρσιμο με ποντίκι/δάχτυλο για βλέμμα και «Στο σημείο» για άμεση μετάβαση. Σε συσκευή αφής υπάρχει μοχλός κίνησης. Το Space ή το κουμπί «Νερό» πυροβολεί προς το κέντρο. Σε συμβατό WebXR: αριστερός μοχλός για μπροστά/πίσω και πλάγια προς την κατεύθυνση του βλέμματος, δεξιός για στροφή 45° γύρω από τη θέση του headset, trigger για νερό/επιλογή και ανοιχτά σημεία τηλεμεταφοράς. Η βάδιση ελέγχει τα όρια, τα εμπόδια και τις ανοιχτές γέφυρες όπως στο desktop. Η επιλογή «Παιχνίδι νερού» επιστρέφει και στον αρχικό μηχανισμό κάρτας/στόχου.

Οι λυμένες σκηνές ανοίγουν για επανεξέταση. Στο 20/20 εμφανίζεται ο αρχικός νοητικός χάρτης, με την παρομοίωση χωριστά από τις τρεις φάσεις. Η επαναφορά μπορεί να αφορά μία ενότητα ή όλη τη διαδρομή. Η αποθήκευση προόδου είναι ανεξάρτητη από τον πρώτο κόσμο και από την παλαιότερη έκδοση.

## Εικόνες και κίνηση

Ο κεντρικός χάρτης έχει νέο συνεχές πανόραμα 2:1 με μεσογειακή κοιλάδα, ποτάμι και μακρινό ναό. Το «Ορίζοντας: εικόνα / απλός» επιτρέπει σύγκριση στον ίδιο χώρο. Οι επιμέρους ενότητες είναι αυλές με τέσσερις όχθες, μικρά ποτάμια και πέντε διαδοχικά περάσματα.

Τα 16 θέματα έχουν οκτώ διαφορετικά καρέ ImageGen, σε κοινό εικονογραφικό ύφος και με πραγματική διαφάνεια. Η πρώτη φιγούρα δοκιμάστηκε μέσα στη σκηνή πριν παραχθούν οι υπόλοιπες. Τα καρέ προετοιμάζονται με FFmpeg σε πραγματικά looping GIF (8 × 220 ms) και padded PNG atlas. Η εφαρμογή διαβάζει τους χρονισμούς από το manifest και στρέφει τα όρθια planes οριζόντια προς τον χρήστη. Οι τέσσερις στατικές εικόνες του χάρτη επαναχρησιμοποιούν το πρώτο καρέ αντίστοιχης σκηνής. Με παύση ή μειωμένη κίνηση προβάλλεται στατικό καρέ.

- `media/sheets/`: αρχικές παραγωγές και διορθώσεις διαφάνειας.
- `media/gifs/`: πραγματικά GIF για αρχειοθέτηση/έλεγχο.
- `media/panorama/`: αρχικό πανόραμα.
- `prompts/`: ακριβή prompts παραγωγής και διορθώσεων.
- `media/sources.json`: επιλογή πηγών και διάταξη καρέ.
- `public/media/manifest.json`: runtime atlas και χρονισμοί.

Τα παλαιά WebP διατηρούνται ως πηγές και εικόνες του τελικού χάρτη. Τα καρέ και ο χειρισμός χρησιμοποιούν τα κοινά αρχεία `shared/journey/`, όπως ο πρώτος κόσμος.

## Ανάπτυξη και έλεγχοι

Από τη ρίζα του αποθετηρίου:

```sh
npm ci
npm run prepare:animations --workspace=apps/theia-oikonomia
npm test
npm run build
npm run dev --workspace=apps/theia-oikonomia
```

Η εφαρμογή ανάπτυξης ανοίγει στη θύρα **5194**. Η προετοιμασία χρειάζεται FFmpeg/FFprobe· το Vite χρησιμοποιεί τα ήδη αποθηκευμένα atlas. Μερική προετοιμασία: πρόσθεσε `-- --only compassion,healing` στην εντολή προετοιμασίας. Κάθε κλήση media έχει όριο 45 δευτερολέπτων και δεν περιμένει είσοδο από τερματικό.

Οι έλεγχοι καλύπτουν τα αρχικά IDs/κείμενα/engine, ολοκλήρωση 0→20, λάθη/υποδείξεις, επαναλαμβανόμενη βολή, αποθήκευση/επαναφορά, διαδοχή γεφυρών, είσοδο από κάθε γέφυρα, παρουσία εικόνων, πραγματικά διαφορετικά καρέ, alpha και χρονισμούς GIF/atlas. Η πραγματική συσκευή VR ελέγχεται χωριστά όταν συνδεθεί headset.
