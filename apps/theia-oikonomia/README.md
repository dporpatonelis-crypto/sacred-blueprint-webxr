# Η Θεία Οικονομία · WebXR

[Άνοιγμα μαθήματος](https://dporpatonelis-crypto.github.io/sacred-blueprint-webxr/lessons/theia-oikonomia/)

Η εφαρμογή ακολουθεί το ίδιο μοτίβο με το «Από το κατ’ εικόνα στο καθ’ ομοίωση»: τέσσερις νησίδες στον κεντρικό χάρτη, επιλογή κάρτας και φωτεινού στόχου, η ίδια αυλή στις επιμέρους ενότητες, οι ίδιες κινήσεις και η ίδια αποθήκευση προόδου. Το εικαστικό υλικό και τα κείμενα προέρχονται από το μάθημα της Θείας Οικονομίας.

Υπάρχουν τέσσερις βασικές αντιστοιχίσεις και τέσσερις συνδέσεις μέσα σε καθεμία, **20 συνολικά**. Η ασθένεια επισημαίνεται ως ιατρική παρομοίωση, ενώ οι άλλες τρεις νησίδες είναι οι φάσεις του σχεδίου. Στην ολοκλήρωση εμφανίζεται ο νοητικός χάρτης με όλες τις έννοιες.

## Περιήγηση

Σύρσιμο με ποντίκι ή δάχτυλο για ματιά, WASD/βελάκια για βάδισμα και «Στο σημείο» για άμεση άφιξη. Σε tablet ή κινητό, κράτησε και σύρε τον μοχλό κάτω αριστερά. Επιλογή κάρτας και κατόπין φωτεινού στόχου, στον πίνακα ή μέσα στον χώρο. Με δύο λάθη εμφανίζεται υπόδειξη. Οι λυμένοι στόχοι ανοίγουν για επανεξέταση.

Το «Ορίζοντας: εικόνα / απλός» συγκρίνει το εικονογραφημένο πανόραμα 360° με τον απλό ορίζοντα στον ίδιο 3D χώρο. Οι γέφυρες και οι αυλές παραμένουν κοινές με το πρότυπο.

## Ανάπτυξη

Από τη ρίζα του αποθετηρίου:

```sh
npm ci
npm run dev --workspace=apps/theia-oikonomia
npm run build
```

Η εφαρμογή ανοίγει στη θύρα 5192. Το συνολικό build περιλαμβάνει τη συλλογή και κάθε δημοσιευμένο μάθημα.

## Περιεχόμενο

Το `src/data/source-lesson.json` κρατά τις τέσσερις ενότητες, τα κείμενα, τις υποδείξεις, τα αποσπάσματα και τη δομή του τελικού mind map. Τα WebP στο `public/media/` είναι οι νέες εικόνες του μαθήματος. Οι λοιποί μηχανισμοί και τα χειριστήρια ακολουθούν το υφιστάμενο WebXR πρότυπο.
