# Το Σχέδιο της Θείας Οικονομίας · WebXR

Ανεξάρτητος κόσμος WebXR στο sacred-blueprint-webxr. Η πηγή είναι το Drive HTML theia-oikonomia-mindmap.html. Οι τέσσερις κεντρικές συνδέσεις και οι δεκαέξι υποσυνδέσεις διατηρούν τις λέξεις, τις ερωτήσεις, τις υποδείξεις, τις ερμηνείες και τις θέσεις τους πάνω στην αρχική σύνθεση.

Η «Ασθένεια» παραμένει εισαγωγική ιατρική παρομοίωση και δεν παρουσιάζεται ως τέταρτη φάση. Οι τρεις φάσεις είναι η Παλαιά Διαθήκη, η Καινή Διαθήκη και η Εκκλησία. Μετά την ολοκλήρωση ανοίγει ο τελικός mind map, όπου οι τρεις φάσεις εμφανίζονται σε διαδοχή και η παρομοίωση σε ξεχωριστό κλάδο.

## Χειρισμός

- Επιλογή λέξης και στόχευση του αριθμημένου σημείου στην εικόνα.
- Σε υπολογιστή: WASD ή βελάκια για κίνηση, σύρσιμο για αλλαγή βλέμματος και κλικ για επιλογή.
- Σε Android κινητό ή tablet: μοχλός κάτω δεξιά για κίνηση και σύρσιμο στον χώρο για αλλαγή βλέμματος.
- Σε συμβατό headset: VRButton και ακτίνες χειριστηρίων.
- Η πρόοδος αποθηκεύεται με ανεξάρτητο κλειδί theia-oikonomia-webxr.v1.

## Τοπική ανάπτυξη

Από τη ρίζα του αποθετηρίου:

    npm run dev --workspace=apps/theia-oikonomia
    npm run build --workspace=apps/theia-oikonomia

Ο συνολικός build παίρνει τη διεύθυνση συλλογής από VITE_COLLECTION_URL. Η προεπισκόπηση του κόσμου βρίσκεται στο site/previews/theia-oikonomia.webp. Δεν έχει γίνει δοκιμή σε φυσικό headset.
