## Media / build

- Πέντε runtime atlases RGBA 1536×1024, 4×2 καρέ 384×512. Οι πέντε τελικές εικόνες έχουν πραγματικά διαφανή pixels και είναι byte-for-byte ίδιες με τα επιλεγμένα masters.
- Πέντε GIF προεπισκοπήσεων, οκτώ καρέ και 2240 ms το καθένα.
- Ο χάρτης GLB ταυτίζεται ως SHA-256 με το αρχικό Unity asset. Τα πανοράματα διατηρούν την προβολή 180°. Το βίντεο διαρκεί 45.013″.
- `npm run build`: επιτυχές production build και των τριών κόσμων και της συλλογής.
- `node --check` στα νέα modules και `git diff --check`: επιτυχή.
- Η production προεπισκόπηση λειτουργεί στη θύρα 5198, χωρίς δημοσίευση στη main.

## Όρια επαλήθευσης

Δεν υπήρχε φυσικό headset ή πραγματικοί XR controllers. Δεν δηλώνεται επιτυχής δοκιμή εισόδου/εξόδου XR, χειρισμών VR ή αναγνωσιμότητας στο headset. Ο κώδικας περιλαμβάνει ελεύθερη tracked κάμερα, ακτίνες επιλογής, XR μενού, ανάγνωση, επαναφορά, teleport και έξοδο βίντεο· απαιτείται χωριστή δοκιμή συσκευής.

Δεν επαληθεύτηκε άμεσα η παύση από πραγματικό `document.hidden` στην ενσωματωμένη προεπισκόπηση. Η παύση ανάγνωσης επαληθεύτηκε ζωντανά, ενώ οι διαδρομές `document.hidden` και XR `visibilityState` ελέγχθηκαν στον κώδικα. Απαιτείται τελική επιβεβαίωση απόκρυψης σε κανονικό browser / συσκευή.
