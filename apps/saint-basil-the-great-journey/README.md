# Μέγας Βασίλειος · WebXR στην Καισάρεια

Κόσμος WebXR με παζλ 4×2 από την εικόνα του βίου, οκτώ διαδοχικούς σταθμούς βιβλικών προσώπων και έξι διαδοχικούς σταθμούς του απολυτικίου. Η σωστή απάντηση γεμίζει το δοχείο, συμπληρώνει το χειρόγραφο και μεταφέρει τη λέξη στην εικόνα.

Τρέχει από τη ρίζα της συλλογής με `npm run dev --workspace=apps/saint-basil-the-great-journey` και ανοίγει στη θύρα 5211. Η πρόοδος αποθηκεύεται χωριστά για αυτόν τον κόσμο. Οι πηγές PNG, το prompt και η προέλευση των εικόνων βρίσκονται εκτός του δημόσιου φακέλου `public/`.
